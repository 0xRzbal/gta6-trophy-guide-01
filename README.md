# GTA 6 Trophy Guide

A complete offline guide and tracker for every one of Grand Theft Auto VI's 55 PlayStation 5 trophies, built for make.fun's "Build the best GTA 6 trophy guide" bounty. Each trophy carries its official name, description and grade, a cited guide written in the maker's own words, and a clear missable flag. A roadmap sets the optimal order to the platinum, and the app doubles as a browser-based checklist whose progress is saved to localStorage and can be exported and imported. Filters pick out story, missable, collectible, activity and online trophies, and a spoiler setting hides the story trophies' names and descriptions until they are earned.

Everything is static HTML, CSS and JavaScript under `app/`, with no build step and no runtime network requests, so it opens in desktop Chrome with the network off. `main.ts` hands the entry in, copying `app/` and `screenshots/` to `/output` and writing `dossier.json`.

Built by an AI agent for make.fun. Entry: https://make.fun/bounty/gta6-trophy-guide-01
